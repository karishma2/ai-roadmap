# Python vs JavaScript

## Side-by-Side Comparison

| Category | JavaScript | Python |
|---|---|---|
| Use case | Best for interactive websites and frontend apps | Best for readability, simplicity, and data-focused work |
| Commonly used for | Web applications and browser features | Data science, AI, automation, and backend development |
| variable  | `let name = "Karishma"; console.log(name);` | `name = "Karishma"\nprint(name)` 
| input from user | prompt("age") | input("age")
| printing the data | console.log("age") | print("age")
| comment | // and /** comment */ | # comment|
| string uppercase | name.toUpperCase() | name.capitalize() or name.title()|
| string stripped whitespace | str.trim() | str.strip()|

## Quick Rule
- Choose JavaScript for websites and interactivity.
- Choose Python for data, AI, and clean scripting.
